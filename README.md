# Overview

FIA-style document latex template.

# Usage

Replace you what to replace. Fill or expand some tabularx. But remember proper use only.  
Font is Arial. Header Image resolution is 1366x120. As there is no CJK character in FIA documents, CJK was not supported.

Build document

```xelatex docuemnt.tex```
